# 跑車收入紀錄

多元化計程車（Uber）司機用的手機網頁工具：記錄上線時間、每趟收入、在哪一區等單，算出淨時薪、哪一區和哪個時段最好賺。

- 網址：https://wudano1.github.io/paoche/
- 免費、不需要登入，也不依賴任何付費服務。
- 紀錄只存在你自己的手機（瀏覽器的本機儲存），不會上傳到任何伺服器。

## 第一次使用

1. 用 iPhone 的 Safari 打開網址。
2. 按下方「分享」→「加入主畫面」。之後從主畫面圖示打開，像 App 一樣全螢幕。
3. 第一次按「開始上線」時，允許使用位置，就會自動判斷你在哪一區。

## 備份

紀錄只存在這支手機。到「設定 → 備份與還原」：

- **下載備份檔**：存成 .json 檔，建議每週一次，再上傳一份到 Google 雲端硬碟。
- **從備份檔還原**：換手機時用，重複的紀錄會自動略過。
- **下載每趟明細（CSV）**：可以直接用 Google 試算表打開分析。

## 預設值來源

- 實拿比例 75%、時段建議（平日中午離峰；週三、五、六 17:00–01:00 黃金時段；週末、下雨、節日全力跑）來自計程車職前講習的 Uber 課程講義。
- 油錢每上線小時 21 元：講義中講師每月加油約 7,300 元 ÷ 每月約 355 個上線小時。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 整個 App |
| `geo.js` | 用 GPS 座標判斷行政區、機場、營業區外 |
| `areas.json` | 北北基桃宜的區域界線 |
| `sw.js` | 離線可用；改版推上來後會自動更新 |
| `manifest.webmanifest`、`icon-*.png` | 加入主畫面用的名稱與圖示 |

## 資料來源

區域界線取自內政部「鄉鎮市區界線（TWD97 經緯度）」（政府資料開放授權條款第 1 版），經 [taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（MIT）簡化。
